# Мои дайджесты — Horizon

Личная подборка из RSS и Telegram: технологии, безопасность, наука, спорт,
шахматы и обучение. Генерация на Mac через Docker и подписку ChatGPT;
готовые выпуски публикуются через GitHub Pages.

- [Читать дайджесты](https://blabla2018.github.io/horizon-personal/)
- [RSS для Inoreader](https://blabla2018.github.io/horizon-personal/feed.xml)

## Где что находится

- `data/config.json` — источники, язык, период, критерии и параметры ИИ.
- `profiles/personal-reading/` — правила отбора и аннотаций.
- `data/summaries/` — выпуски в Markdown.
- `docs/` — готовая HTML-страница, архив и RSS с полным текстом.
- `build.py` — преобразование Markdown в HTML и RSS без обращения к ИИ.
- `run-local.sh` — сбор, восстановление ссылок Telegram, формирование страницы.
- `telegram_links.py` — точные ссылки на посты Telegram и их веб-превью.

В репозитории 20 RSS-подписок (14 включены) и пять Telegram-каналов.
Лимит количества записей отсутствует; порог отбора 4/10.
Период — последние 168 часов. При двух запусках в неделю периоды перекрываются,
поэтому некоторые статьи могут повторяться между выпусками.

## Запуск на Mac

Нужны Docker/Colima, Git и uv. Для публикации используются подключённые
инструменты GitHub в Codex либо ваш авторизованный Git. Скопируйте `.env.example` в `.env`, укажите RSS Хабра
и подготовьте локальную авторизацию Horizon ChatGPT. OAuth-токены находятся
в отдельной папке `../horizon-auth`, вне репозитория. Регистрация и обновление
OAuth-сессии выполняются средствами Horizon; токены на GitHub не передаются.

```bash
docker compose build horizon
sh run-local.sh
```

После генерации публикуются только `data/summaries/` и `docs/`.
Автоматизация Codex делает это через подключение GitHub, без локального PAT.
При ручном использовании авторизованного Git: `git add data/summaries docs`,
затем `git commit` и `git push`.

Для пересборки только HTML и RSS из уже готовых выпусков:

```bash
uv run --with markdown==3.10.2 python build.py
```

Используется Horizon [Thysrael/Horizon](https://github.com/Thysrael/Horizon)
на зафиксированной версии `12d5fbde4d9e0776a48618ea65d16fe6d1e1b606`.
Изменения его внутреннего кода не требуются.

## Публикация и чтение

GitHub Pages публикует папку `docs` ветки `main`.
В Inoreader добавляется URL `https://blabla2018.github.io/horizon-personal/feed.xml`.
Один выпуск — одна запись с полным текстом и ссылками на оригиналы.
HTML адаптирован под компьютер и планшет, содержит оглавление и тёмную тему.

Репозиторий и дайджесты публичны. `.env`, персональная RSS-ссылка Хабра,
ключи и OAuth-сессии исключены из Git. Подписки Inoreader скопированы вручную;
автоматической синхронизации нет. National Geographic в последней проверке
отвечал HTTP 403. YouTube читается по заголовкам/описаниям, не по транскриптам.
Telegram ограничен публичным веб-превью; полный недельный архив не гарантируется.

Желаемое расписание: вторник и пятница, 12:00, Europe/Madrid.
Сбор выполняется на Mac; Mac должен быть включён и подключён к интернету.
