# Мои дайджесты — Horizon

Еженедельная подборка из RSS, Hacker News и Telegram: security, AI и история компьютеров. Генерация на Mac через Docker и подписку ChatGPT;
готовые выпуски публикуются через GitHub Pages.

- [Читать дайджесты](https://blabla2018.github.io/horizon-personal/)
- [RSS дайджестов](https://blabla2018.github.io/horizon-personal/feed.xml)

- [RSS отдельных новостей](https://blabla2018.github.io/horizon-personal/news.xml)

## Где что находится

- `data/config.json` — источники, язык, период, критерии и параметры ИИ.
- `profiles/personal-reading/` — правила отбора и аннотаций.
- `data/summaries/` — выпуски в Markdown.
- `docs/` — готовая HTML-страница, архив и RSS с полным текстом.
- `build.py` — преобразование Markdown в HTML и RSS без обращения к ИИ.
- `run-local.sh` — сбор, восстановление ссылок Telegram, формирование страницы.
- `telegram_links.py` — точные ссылки на посты Telegram и их веб-превью.

## Источники и отбор

Включены RSS: AdGuard Blog, Ars Technica — Technology Lab, Securelist, Касперский,
BleepingComputer и Simon Willison. Hacker News: первые 100 текущих top stories,
от 100 голосов. Это срез текущего рейтинга HN, а не полный архив за неделю.
Telegram: it_secur, Social_engineering, durov, data_secrets, matvei_vibecoding.
Смешанные источники проходят тематический отбор.

Хабр, Medium, спорт/велоспорт, шахматы, наука и образовательные каналы выключены
в Horizon. Исходные подписки в Inoreader не изменяются. Выключенные записи
сохранены в конфигурации для справки, в сбор не попадают.

Период — последние 168 часов. Один выпуск в пятницу, 12:00 Europe/Madrid.
Не более 30 публикаций: порог 6/10, затем смысловая дедупликация и отбор
по оценке. История компьютеров и интернета (Norton Commander, ICQ, DOS,
классическое ПО и устройства) — высокий личный интерес, ориентир 8–9/10
для содержательных материалов. Объём не дополняется слабыми статьями до 30.
URL- и смысловая дедупликация уменьшают повторы внутри выпуска, но не гарантируют
идеальное объединение всех пересказов одного события.

## Запуск на Mac

Нужны Docker/Colima, Git и uv. Для публикации используются подключённые
инструменты GitHub в Codex либо ваш авторизованный Git. Скопируйте `.env.example` в `.env` и подготовьте локальную авторизацию Horizon ChatGPT. OAuth-токены находятся
в отдельной папке `../horizon-auth`, вне репозитория. Регистрация и обновление
OAuth-сессии выполняются средствами Horizon; токены на GitHub не передаются.

```bash
docker compose build horizon
sh run-local.sh
```

После генерации публикуются только `data/summaries/` и `docs/`.
Автоматизация Codex делает это через подключение GitHub, без локального PAT.
При ручном использовании авторизованного Git: `git add data/summaries docs`,
затем `git commit` и `git push`.

Для пересборки только HTML и RSS из уже готовых выпусков:

```bash
uv run --with markdown==3.10.2 python build.py
```

Используется Horizon [Thysrael/Horizon](https://github.com/Thysrael/Horizon)
на зафиксированной версии `12d5fbde4d9e0776a48618ea65d16fe6d1e1b606`.
Изменения его внутреннего кода не требуются.

## Публикация и чтение

GitHub Pages публикует папку `docs` ветки `main`.
В Inoreader добавляется URL `https://blabla2018.github.io/horizon-personal/feed.xml`.
`feed.xml`: один выпуск — одна запись с полным текстом и ссылками на оригиналы.
`news.xml`: одна статья — одна запись с аннотацией и прямой ссылкой на оригинал.
Обе ленты строятся из тех же отобранных материалов, дополнительных AI-вызовов нет.

Все датированные Markdown-выпуски сохраняются. При сборке XML-файлы технически
перезаписываются, но включают весь сохранённый архив, а не только последнюю неделю.
GUID дайджеста зависит от даты выпуска; GUID новости — от исходного URL без
рекламных меток и фрагмента. Веб-превью и обычные ссылки Telegram нормализуются
к одному посту. Повтор той же ссылки в другом выпуске не создаёт новую запись
в `news.xml`: сохраняются первая аннотация и дата её публикации. Читатель получает
только новые GUID; прочитанное/избранное остаётся состоянием самого Inoreader.
Похожие события по разным URL могут появиться снова на следующей неделе:
смысловая дедупликация Horizon работает внутри отдельного запуска, а не глобально.
Обновление уже существующей статьи по тому же URL не создаёт новую новость.
HTML адаптирован под компьютер и планшет, поддерживает тёмную тему.
Содержание и повторяющиеся названия разделов исключены из HTML и RSS; RSS содержит только статьи.

Репозиторий и дайджесты публичны. `.env`, персональная RSS-ссылка Хабра,
ключи и OAuth-сессии исключены из Git. Подписки Inoreader скопированы вручную;
автоматической синхронизации нет.
Telegram ограничен публичным веб-превью; полный недельный архив не гарантируется.

Расписание автоматизации Codex: пятница, 12:00, Europe/Madrid.
Сбор выполняется на Mac; Mac должен быть включён и подключён к интернету.


## Ежедневная группа «Техноновости»

- Каналы: `bugnotfeature`, `media1337`.
- [RSS](https://blabla2018.github.io/horizon-personal/tech-news.xml) и [страница](https://blabla2018.github.io/horizon-personal/tech-news.html).
- Настройки: `groups/tech-news.json`; правила очистки/рейтинга: `groups/tech-news.prompt.md`.
- Запуск: `sh run-daily.sh`. Использует существующие scraper и AI client Horizon с той же OAuth-сессией.
- Сбор раз в день, 12:00 Europe/Madrid. Веб-превью читается с перекрытием 7 дней, максимум 4 страницы на канал; это не гарантирует полный исторический архив или восстановление после долгого перерыва.
- Обрабатываются текстовые посты; фото/видео доступны по ссылкам на оригиналы, их содержимое не распознаётся.
- Все нерекламные новости сохраняются, включая мемы и новости с низким личным интересом. Лимита 30 для этой ленты нет.
- Рейтинг 0–10 указан в заголовке RSS и начале текста; это личный интерес, а не оценка достоверности.
- Порог сейчас выключен: `"min_score": null`. Для будущего порога задайте, например, `6` и пересоберите ленту. Это скрывает записи из выдаваемого RSS, но не стирает архив и уже сохранённые записи Inoreader.
- Чисто рекламные посты исключаются; у смешанных новостей удаляются рекламные окончания. При сомнении пост сохраняется. AI-определение рекламы и дублей может ошибаться.
- Дубли внутри партии и повторы последних 200 опубликованных новостей объединяются с сохранением ссылок на источники. Существенные новые факты должны становиться новой записью.
- `data/groups/tech-news.json` — публичный накопительный архив очищенных новостей и идентификаторов обработанных постов. Его обязательно сохранять и публиковать вместе с `docs/tech-news.*`.
- `data/groups/tech-news-audit.json` — локальный отчёт об исключённой рекламе, игнорируется Git. Промежуточный `tech-news-pending.json` также игнорируется; он позволяет продолжить незавершённый сбор. После завершения всех партий сохраняется основной архив.
- Повторный запуск не переоценивает уже обработанные посты. GUID и первая дата опубликованной новости сохраняются. При новой ссылке на старую новость добавляется источник, а новая запись не создаётся.
- Повторный экспорт без AI: `python3 daily_feed.py --export-only`.

Существующие недельные `feed.xml` и `news.xml` используют прежние источники, порог 6 и лимит 30. Ежедневная группа в них не подмешивается.
